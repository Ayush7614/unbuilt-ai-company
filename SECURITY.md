# Security Policy

## Status

This is an experimental educational reference implementation, not a production-hardened service.

## Reporting a vulnerability

Please do not publish exploitable details in a public issue. Until a dedicated security contact is configured, contact the repository owner privately through GitHub's security advisory feature if it is enabled.

## Current limitations

- Authentication and authorization are not implemented in the initial API.
- The API is intended for local development only.
- Do not expose it to the public internet.
- Do not provide it with production credentials or sensitive personal data.
- Approval workflows and audit controls are not yet implemented.
