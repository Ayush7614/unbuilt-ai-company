# Contributing

Thanks for helping improve Unbuilt AI Company.

1. Open an issue describing the problem or proposed change before substantial work.
2. Keep changes scoped and document relevant design decisions.
3. Add or update tests for behavior changes.
4. Run `python -m pytest -q` from `services/api` before submitting.
5. Never commit secrets, private customer data, or unlicensed third-party assets.
6. Clearly distinguish implemented behavior from planned behavior in documentation.

By submitting a contribution, you agree that your contribution is provided under the license stated in the relevant directory.
